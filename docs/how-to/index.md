# How-To Guides

Task-oriented guides for competent users and desktop integrators. Each guide assumes you have completed [Getting Started](../tutorials/getting-started.md) and understand basic CLI usage.

---

## Guides

| Guide | Solves |
| :--- | :--- |
| [Configure Keybindings and Aliases](configure-keybindings.md) | Map custom single keys, vim chords, and modifier combinations; define aliases and suppress default bindings. |
| [IPC Scripting and Automation](ipc-scripting-and-automation.md) | Control running Unframed instances via UNIX domain sockets, integrate with window managers (Sway / Hyprland), and execute shell commands. |
| [Customizing the OSD Overlay and Window Title](customizing-overlay-and-status.md) | Format overlay templates with metadata variables, style fonts and colors, and customize the window title. |
| [Slideshow and Animation Controls](slideshow-and-animation-controls.md) | Configure automated slideshows, step through animated GIF/WebP frames, and pause or resume playback. |

For the full command reference, consult the [Command Reference](../reference/commands.md).
